# 夕闇通り探検隊 (Yuuyami Doori Tankentai) — English translation project

PlayStation, Spike, 1999, serial **SLPS-02274** (NTSC-J). An English patch for the game: every line of dialogue and the
menus, notebook, map labels and title screen.

> **Status: raw machine-translated first pass.** All 87,028 lines of dialogue and nearly all menu graphics have English, and the
> opening hours have been played through in an emulator, but the translation is literal and unpolished, was produced by an AI
> from Japanese text recovered by glyph recognition (so a few kanji are probably wrong), and **large parts of the game have
> not been played-tested**. It is a starting point. **We want people who read Japanese, know the game, or just want to play and
> report problems.**

No game data is in this repository and none ever should be. You need your own dump of the game.

## Just want to play it?
1. Get your own dump of the Japan release: `Yuuyami Doori Tankentai (Japan).bin/.cue`, MODE2/2352, **CRC32 `9d2b1afe`**.
2. Download the latest `.xdelta` from [Releases](../../releases) and apply it to the `.bin` with
   [xdelta UI](https://github.com/janisslsm/xdeltaui), Delta Patcher, or `xdelta3 -d -s original.bin patch.xdelta ydt_en.bin`.
3. Use the original `.cue` (rename it to match) and play in DuckStation / any PS1 emulator. See [docs/PATCHING.md](docs/PATCHING.md).

Please report bugs (line overflow, garbled text, wrong kanji, crashes) as Issues. Tell us the scene and, if you can, the
line ID: see "Finding a line" in [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

## Want to improve the translation?
Read [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md). In short: run `tools/setup.py` on your own dump (it regenerates the Japanese
script locally), edit English in `translation/en/NNNN.json`, rebuild your own disc with one command, test, open a pull request.
The repository holds **English only**; the Japanese stays on your machine.

## How does it work?
[docs/WRITEUP.md](docs/WRITEUP.md) explains how the text was found, the file formats, how the disc is rebuilt, and what is and
isn't verified. No EXE patching is involved: the game draws dialogue from per-scene bitmap fonts, so we swap the font and text
in the data files and rebuild the disc image.

## Layout
| path | what |
|---|---|
| `translation/en/` | **the translation**: one JSON per scene file, English only (`en_raw` = first pass, `en` = human edit, wins if set) |
| `translation/ui/eas_text.json` | menu/graphic text (generated by `tools/mk_ui.py`; edit that, not the JSON) |
| `translation/glossary/` | names and terms |
| `translation/context/INDEX.tsv` | per-file scene group, characters, first line |
| `translation/tables/` | glyph recognition tables (hashes + labels, no game data) |
| `tools/` | extraction, build, checks (Python 3, numpy, pillow; gcc for the optional sector checker) |
| `docs/` | write-up, contributing guide, patching guide, findings, prior-work notes, `archive/` = early planning docs (obsolete) |
