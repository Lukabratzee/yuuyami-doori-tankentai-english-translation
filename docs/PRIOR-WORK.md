# Other work on this game

This project is not the only effort, and we would rather help than duplicate.

- **dothacktranslate** announced a human-translated English patch project (romhacking.net forum, topic 41595; RetroGameTalk
  thread 26808). They reported working out the game's formats and extracting the script. If you are part of that effort: hello.
  Everything here is open, so take whatever is useful, and if you'd like the machine first pass as a reference or want to share
  findings, please open an Issue.
- A machine-translated English patch is listed on CDRomance. Its method is unknown to us and nothing here is derived from it.
- A guidebook translation project (LucidSD, romhacking.net topic 27459) and the official strategy guide scan on archive.org are
  good terminology references.

We did not use code, scripts or tables from any other project. Everything in `tools/` was written from the disc image alone.
This project's raw pass is machine-translated and labelled as such; some hosts restrict AI-translated patches, so check the
host's rules before mirroring any release.
