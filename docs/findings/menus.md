# Findings: menu and system text (2026-11-16)

**Menus are pictures, not text.** Title menu, Yes/No, date labels and every memory-card message are pre-drawn images
inside `EAS 1.00` files. There is no Shift-JIS UI text anywhere (EXE and all system directories scanned: only the
memory-card save title in `d000`, which is the name shown in the PlayStation memory-card manager — leave it).

## EAS 1.00 format (see `tools/eas.py` docstring for the field list)
Header 0x38, image table of 20-byte entries (id, origin, w, h, bpp 4|8, END offset of pixels), palette section, pixel data.
**Row stride = image byte size / height** (rows are padded — assuming w/2 gives skewed pictures). 4bpp, low nibble = left.
Translating an image = redrawing it at the **same size**, so the file never changes size and nothing has to move.

## How to translate one
1. `python3 tools/eas.py montage <leaf> work/eas/x.png` → find the image numbers that contain Japanese.
2. Add them to `translation/ui/eas_text.json`: `{"<leaf>": {"<image no>": "English"}}`.
3. `python3 tools/eas.py montage <leaf> work/eas/x_en.png preview` → check the redraw.
4. `tools/build_disc.py en …` applies the file automatically (same-size, in place).
Text is auto-shrunk to fit the box (DejaVu Sans Bold, max 12 px) and coloured by a heuristic (background = top-left
pixel, fill = most common other colour, outline = next). Where that looks wrong (e.g. the Yes/No boxes), the image needs
hand-drawing or a smarter colour pick. Long memory-card messages will not fit one line at readable size: `text_rows`
needs multi-line support first.

## Update 2026-11-17: menus translated (383 images in 49 leaves)
All UI text is generated by `tools/mk_ui.py` into `translation/ui/eas_text.json` (re-run it after editing; do not hand-edit
the JSON). `tools/eas_sheet.py <leaf> out.png A-B [scale]` draws a readable contact sheet. Styles live in `tools/eas.py`
(`styled_rows`): `hand` (notebook pencil, keeps the original slant; `segs` places option words in the original word slots
so the game's highlight boxes line up), `cap`, `help`, `msg`/`msgdark`, `save`, `btn`, `ramp`, `auto` (map labels: picks
background from the border and ink from brightness percentiles), plus `_disclaimer` for the full-screen notice.

Done and checked in DuckStation: fiction disclaimer (d003), title date/New Game, notebook topics, all 44 rumor names (notebook
and caption bar), Settings page (labels, options, help captions), OK/Cancel/Map buttons everywhere, town-map labels and
map help, pause menu (already English).
Drawn but not yet seen in-game: memory-card messages (title d004, save screen d012), save/purify prompts (d011, d013),
HUD day/weekday glyphs (d005), walk-start labels (d006/f008).

Lessons:
- **Notebook pencil is drawn with subtractive blending**: high palette index = darker pencil. Ink 14/11/7 on bg 15.
- **Visible text width is ~265 px**, not 320 (overscan crop). Dialogue font switched to DejaVu Sans Condensed 11 and
  `check_script.py` MAX_PX lowered to 256.
- The notebook date header reuses the weekday kanji 月 (Mon) and 日 (Sun) as "month"/"day", so it is left in Japanese.
- Not translated: staff credits (d011/f001-2), per-area map snippets d002/f543-578 images 15-18 (street names).
